## defects inventory

### defect 1: @src/domain path alias not found

**what**: 70 type errors - `Cannot find module '@src/domain'`

**how** (diff against origin/main):
- domain objects moved from `src/domain/objects/` to `src/domain.objects/`
- `src/domain.objects/index.ts` only exported `./constants`, not the domain objects
- `src/domain.objects/constants.ts` imported from `./objects` which doesn't exist
- tsconfig paths `@src/*` maps to `src/*` but `src/domain/` directory was removed

**why** (root cause): declapract restructured domain objects into new convention `domain.objects/` (with dot separator). imports from `@src/domain` still expected the old `src/domain/` path structure. additionally, the new index.ts was incomplete (only exported constants) and constants.ts had broken imports.

**fix**:
1. fixed `src/domain.objects/constants.ts` - updated imports from `./objects` to individual files
2. fixed `src/domain.objects/index.ts` - added exports for all domain object files
3. created `src/domain/index.ts` - re-exports from `../domain.objects` for backwards compatibility

### defect 2: test assets path changed

**what**: 3 test failures in `extractSqlFromTsFile.test.ts` - ENOENT for test asset files

**how** (diff against origin/main): test assets moved from `__test_assets__/` to `.test.assets/`

**why** (root cause): declapract convention change from `__test_assets__/` to `.test.assets/` (dot prefix convention). test file still referenced old path.

**fix**: updated `extractSqlFromTsFile.test.ts` - changed `TEST_ASSETS_DIR` from `__test_assets__` to `.test.assets`

### defect 3: biome lint errors

**what**: 2 lint errors from biome check

**how** (diff against origin/main): biome replaced eslint+prettier

**why** (root cause): biome has different rules than eslint:
1. `noDefaultExport` - forbids default exports (oclif requires them for commands)
2. `noSparseArray` - forbids sparse arrays like `[, null]`

**fix**:
1. added `// biome-ignore lint/style/noDefaultExport` comment to `generate.ts`
2. changed `[, null]` to `[undefined, null]` in `extractTypeDefinitionFromTableReference.ts`

### defect 4: dpdm circular dependency detection

**what**: lint:cycles failed on circular dependencies

**how** (diff against origin/main): new `.dpdmrc.yaml` config added, `npm run test:lint:cycles` command added

**why** (root cause): declapract introduced dpdm for circular dependency detection. code has pre-extant intentional mutual recursion for nested subquery extraction. node_modules also detected.

**fix**: updated `.dpdmrc.yaml` to exclude:
1. `node_modules` - external dependencies
2. `extractSelectExpressionsFromQuerySql` - intentional mutual recursion
