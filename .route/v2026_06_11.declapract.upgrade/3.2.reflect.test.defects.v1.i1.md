## classifications

### defect 1: @src/domain path alias not found

**classification**: practice bug

**reason**: declapract has `directory-structure-src/bad-practices/domain-dir` and `old-import-paths` practices that should migrate `src/domain/` to `src/domain.objects/`. however, the migration did not update all dependent imports, and `src/domain.objects/index.ts` was created with incomplete exports.

**citation**:
```
gh search code --repo ehmpathy/declapract-typescript-ehmpathy "domain.objects"
```
found practices at:
- `src/practices/directory-structure-src/bad-practices/domain-dir/`
- `src/practices/directory-structure-src/bad-practices/old-import-paths/`

**feedback**: the practices need to ensure:
1. `src/domain.objects/index.ts` exports all domain objects (not just constants)
2. `src/domain.objects/constants.ts` imports are updated to new paths
3. a `src/domain/index.ts` re-export is created for backwards compat with `@src/domain` alias

### defect 2: test assets path changed

**classification**: practice bug

**reason**: declapract has `tests/bad-practices/old-test-utils-and-assets-location` practice that migrates `__test_assets__/` to `.test.assets/`. however, the test file references to these directories were not updated.

**citation**:
```
gh search code --repo ehmpathy/declapract-typescript-ehmpathy "test.assets"
```
found practice at:
- `src/practices/tests/bad-practices/old-test-utils-and-assets-location/`

**feedback**: the practice updates import paths but not variable assignments like `const TEST_ASSETS_DIR = \`${__dirname}/__test_assets__\``. these patterns should also be migrated.

### defect 3: biome lint errors (noDefaultExport)

**classification**: repo quirk

**reason**: oclif framework requires default exports for CLI commands. this conflicts with biome's `noDefaultExport: error` rule. CLI repos need an exception.

**citation**:
```
gh search code --repo ehmpathy/declapract-typescript-ehmpathy "noDefaultExport"
```
found `"noDefaultExport": "error"` in `src/practices/lint/best-practice/biome.jsonc`

**feedback**: consider oclif command pattern in biome ignore list, or document that CLI repos need this exception.

### defect 3b: biome lint errors (noSparseArray)

**classification**: adoption candidate

**reason**: `[, null]` sparse array is unclear. `[undefined, null]` is explicit and readable. biome caught a legitimate code quality issue.

**feedback**: none needed — biome rule is correct, code was fixed appropriately.

### defect 4: dpdm circular dependency detection

**classification**: repo quirk

**reason**: `extractSelectExpressionsFromQuerySql` has intentional mutual recursion for recursive descent SQL parse. this is a domain-specific pattern in sql-code-generator, not a general issue.

**feedback**: none needed — repo-specific exclusion is appropriate.

### defect 5: unused dependencies

**classification**: practice bug

**reason**: declapract replaced several dependencies but did not remove the old ones:
- `@tsconfig/node-lts-strictest` → `@tsconfig/node20` + `@tsconfig/strictest`
- `core-js` → no longer needed
- `ts-jest` → `@swc/jest`
- `ts-node` → `tsx`

**citation**:
```
gh search code --repo ehmpathy/declapract-typescript-ehmpathy "ts-jest"
gh search code --repo ehmpathy/declapract-typescript-ehmpathy "node-lts-strictest"
```
found practices at:
- `src/practices/tests/bad-practices/deprecated-test-deps/` — detects ts-jest as deprecated
- `src/practices/lint/bad-practices/depcheck-denylisted-ignores/` — denylists ts-jest and @tsconfig/node-lts-strictest

**feedback**: when practices introduce replacement dependencies, they should also remove the old deps from `package.json`. or run `depcheck` as part of the upgrade and auto-fix.
