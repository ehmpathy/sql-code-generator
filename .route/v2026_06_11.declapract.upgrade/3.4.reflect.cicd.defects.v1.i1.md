# 3.4.reflect.cicd.defects

## defect 1: keyrack extends invalid role

### classification: repo quirk

### rationale

the defect is specific to this repo's configuration:
- the declapract template includes `repo=bhuild/role=dispatcher` in keyrack extends
- this repo's `prepare:rhachet` roles list does not include dispatcher
- therefore, the symlink is never created in CI

the template is not wrong — dispatcher is a valid role used by other repos. this repo simply doesn't use it.

### evidence

searched declapract-typescript-ehmpathy for related issues:
```sh
gh search issues "keyrack dispatcher" --repo ehmpathy/declapract-typescript-ehmpathy
# no results
```

the template contains dispatcher by design:
```sh
gh search code "repo=bhuild/role=dispatcher" --repo ehmpathy/declapract-typescript-ehmpathy
# found in .agent/keyrack.yml
```

### action

no feedback to infrastructure needed. the fix (remove dispatcher from extends) is repo-specific.

### lesson

when you add keyrack extends, verify each extended role is in the `prepare:rhachet` roles list. symlinks are only created for roles explicitly listed there.
