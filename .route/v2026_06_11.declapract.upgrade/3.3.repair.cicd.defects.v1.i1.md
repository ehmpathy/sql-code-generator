# 3.3.repair.cicd.defects inventory

## defect 1: keyrack extends invalid role

### what
CI fails with `BadRequestError: extended keyrack not found` for `.agent/repo=bhuild/role=dispatcher/keyrack.yml`

### how
the upgrade added `.agent/keyrack.yml` with extends:
```yaml
extends:
  - .agent/repo=bhrain/role=reviewer/keyrack.yml
  - .agent/repo=bhuild/role=dispatcher/keyrack.yml  # <-- not in roles list
  - .agent/repo=ehmpathy/role=mechanic/keyrack.yml
```

but `prepare:rhachet` only creates symlinks for roles in its list:
```json
"prepare:rhachet": "rhachet init --keys --hooks --roles mechanic behaver driver reviewer librarian ergonomist architect"
```

`dispatcher` is not in the list, so the symlink is never created in CI.

### why
the upgrade's keyrack.yml template includes dispatcher, but the repo's prepare:rhachet command doesn't include dispatcher in its roles.

### fix
removed dispatcher from extends in `.agent/keyrack.yml`
